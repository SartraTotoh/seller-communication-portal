3 · Shared patterns

ใช้หลักเดียวกันทั้งสองพอร์ทัล
Navigation EN + ไทย tooltip
▸ Label EN เป็น base ครบทุกเมนู
▸ คำอธิบายไทยแสดงเป็น tooltip บนคำที่มีเส้นประใต้ (hover)
▸ เมนูเทคนิคถูกซ่อนจากหน้า User → เฉพาะ Owner/Admin เห็น
Content ข้อมูลจริง
▸ Card / Table / Timeline แสดงเฉพาะใน Content zone
▸ ไม่มีโซนข้อมูลใน nav — nav ทำหน้าที่นำทางเท่านั้น
Search compact
▸ ช่องค้นหาสั้น อยู่ขวาบนของหน้า (Ctrl K)
▸ แสดงผลเป็น drop-down ไทยใต้ช่องค้นหาเท่านั้น
Status / SLA color = state
▸ เขียว = on-track · น้ำเงิน = in-review · เหลือง = at-risk · แดง = late
▸ สีใช้เพื่อบอกสถานะ ไม่ใช่เพื่อตกแต่ง
